# Robot CAD

Onshape for VEX V5: a self-paced CAD book for Spartan Design Robotics (Team 2822). Same layout as [Model & Make](https://spartandesign.github.io/model-and-make/) and [Build & Code](https://spartandesign.github.io/build-and-code/). No build step.

- `docs/` is the website (GitHub Pages: branch `main`, folder `/docs`). It goes live at `https://spartandesign.github.io/robot-cad/`.
- `docs/nav.js` is the table of contents. `docs/learn.js` holds the read-aloud, quiz, and plan tools. `docs/robotcad.js` holds the robotics practice tools.
- Hardware facts come from the VEX Library (kb.vex.com). Game rules: always the current V5RC game manual.
