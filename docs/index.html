How to use this book

Every module gives you a mission card with your goal and limits, a meeting-by-meeting plan, a narrated video, a read-aloud, a practice tool, step-by-step tutorials, an engineering-notebook checklist, and a self-check.

Main course: Onshape’s free CAD for Robotics Competitions learning path. Each module links the Onshape unit to do with it.
