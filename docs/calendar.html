For the teacher: prep from Onshape’s unit guides

  • Before Week 1: make an Onshape Team for Period 2 (My Account → Teams) so you can share lesson documents with everyone at once. A Google Form is a quick way to collect student emails.
  • Week 1 scavenger hunt (Intro to Onshape): run it with one shared copy so students see each other’s comments and tags, or have each student copy it.
  • Drivetrain weeks: put real V5 parts (or one built drivetrain) on the tables. Handling the parts helps students read them in 3D.
  • Collaboration: Link Tab has to be added to each student’s account. OneIPM is free for FRC only, so skip it. Start squads on single-document robots.
  • Manufacturing: the CNC lesson is optional (no CNC on site). Remind students to keep the laser lens clean.
  • Display: lessons work best with the lesson on one half of the screen and Onshape on the other.
